# สวนประจำวัน: กระดานสุ่มจากวันที่ + ปฏิทินดอกไม้ แทนการเติมด่านอย่างเดียว

แม่เล่นครบ 60 ด่านแล้วเลิกเปิดเกม อาการคือ "ไม่มีเหตุให้กลับมา" ไม่ใช่ "ด่านน้อยไป" — เติมด่านเพิ่มอย่างเดียวแก้ได้ชั่วคราว จบอีกก็เงียบอีก จึงเพิ่มเนื้อหาที่งอกใหม่เองทุกวันควบคู่ไปกับด่านชุดใหม่

ดีไซน์ที่เลือก: ทุกวันมีกระดาน 1 กระดานที่สร้างจาก seed = วันที่ (deterministic — เครื่องไหนก็ได้กระดานเดียวกัน ไม่ต้องมีเซิร์ฟเวอร์) เล่นจบแล้วดอกไม้บาน 1 ดอกลงปฏิทินรายเดือน ดอกต่างกันตามฤดู สะสมไปเรื่อยๆ เห็นเป็นสวนเต็มหน้า

กันความกดดันตาม [ADR-0003](0003-kindness-model.md): ไม่มี streak ที่ขาดแล้วเสีย, วันที่ไม่ได้เล่นคือช่องว่างเฉยๆ ไม่มีสีแดง/คำว่าพลาด, **ย้อนกลับไปเล่นวันเก่าได้ทุกวันไม่จำกัด** (ดอกที่ขาดเติมได้เสมอ), ความยากสุ่มแต่อยู่ในกรอบใจดี (move limit +40% และ Mercy Moves ทำงานเหมือนด่านปกติ)

## Consequences

- SaveData ขึ้น version 2: เพิ่ม `dailyFlowers` (รายการวันที่ที่บานแล้ว) ต้องเขียน migration จาก v1 — ข้อมูลผู้เล่นย้อนกลับยาก จึงบันทึกเป็น ADR
- ตัวสร้างกระดานต้องอยู่ใน `src/core/` และ pure/deterministic เต็มตัว เพื่อเทสต์ได้ว่าทุกวันในหลายปีข้างหน้าสร้างกระดานที่เล่นจบได้จริง
- กระดานสุ่มไม่ผ่านสายตาคน = คุณภาพต่อกระดานสู้ด่านที่ออกแบบมือไม่ได้ ยอมแลกกับการที่มันไม่มีวันหมด
